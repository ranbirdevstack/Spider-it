# Spider IT | Digital Experience

A sleek, ultra-responsive, and modern single-page corporate website built with semantic HTML5, CSS Grid/Flexbox, and modern vanilla JavaScript. Optimized for accessibility (WCAG compliance), speed, and native cross-platform theme toggling.

🚀 **Live Deployment URL:** https://spider-it.vercel.app/

---

## ✨ Features

- **🌓 Native Light/Dark Mode:** Instant theme swapping backed by browser persistence (`localStorage`) and automatic system scheme detection (`prefers-color-scheme`).
- **📱 Responsive Layout:** Breakpoint-fluid layout engine featuring an interactive hamburger drawer navigation menu optimized for mobile, tablet, and desktop viewports.
- **♿ WCAG Accessible:** Includes structural "Skip to main content" utility hooks, screen-reader optimized SVG icons (`aria-labels`), and explicit landmark navigation elements.
- **⚡ Performance First:** Implements throttled (`debounced`) window manipulation listeners and asset loading optimization to eliminate the "Flash of Unstyled Content" (FOUC).

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5 Structure
- **Styling:** CSS3 Custom Properties (Variables), Flexbox layouts, Responsive Grid architectures
- **Interactions:** Vanilla JavaScript (ES6+ Code Core)
- **Hosting Engine:** Vercel
